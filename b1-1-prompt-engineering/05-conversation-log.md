# 05. 10턴 이상 실행 로그

## 시나리오

사용자가 교육 미션 또는 공모전 공고문을 제공하고, AI가 제출 요구사항을 정리한 뒤 조건 변경을 반영하면서 최종 제출문서 초안을 완성한다.

## 문맥 유지 검증 기준

- 이전에 확정한 요구사항을 유지한다.
- 조건 변경이 들어오면 변경된 부분만 반영한다.
- 개인정보와 민감정보를 노출하지 않는다.
- 문서에 없는 사실은 확인 필요로 표시한다.
