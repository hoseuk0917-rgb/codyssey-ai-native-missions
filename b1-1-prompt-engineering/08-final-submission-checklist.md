- [ ] 사용 날짜 기록
- [ ] 주요 설정 기록

## 문서 2 — 시스템 설계 문서

### 업무 과업 정의

- [ ] 업무 자동화 과업 1개 선택 및 문제 정의
- [ ] 타겟 사용자 명시
- [ ] 입력 데이터 형태 명시
- [ ] 출력 규격 명시
- [ ] 입력 템플릿 1개 이상 제시

### 페르소나

- [ ] 이름
- [ ] 역할
- [ ] 전문 분야
- [ ] 말투
- [ ] 금지 사항
- [ ] 우선순위

### 시스템 프롬프트

- [ ] 역할
- [ ] 목표
- [ ] 출력 형식 규칙
- [ ] 안전장치
- [ ] 사실·정책·수치 처리 규칙

### Few-shot 예시

- [ ] 예시 최소 3개 포함
- [ ] 좋은 입력 → 좋은 출력 예시 2개 이상 포함
- [ ] 모호한 입력 케이스 1개 포함
- [ ] AI가 되물어야 하는 지점 명시

### 프롬프트 개선 이력

- [ ] v1 프롬프트 전문 포함
- [ ] v2 프롬프트 전문 포함
- [ ] v1 → v2 개선 이유 기록
- [ ] 변경 내용 기록

### 환각 검증

- [ ] 검증 질문 5개 이상
- [ ] 각 질문별 기대 정답 기록
- [ ] 각 질문별 판정 기준 기록
- [ ] 각 질문별 참고 근거 기록

## 문서 3 — 실행 로그

- [ ] 선정한 업무 과업 시나리오로 10턴 이상 실제 대화 수행
- [ ] 중간 조건 변경 또는 추가 정보 제공 상황 최소 1회 포함
- [ ] 문제 발생 지점 기록
- [ ] 문제 수정 결과 요약 기록
- [ ] 섹션 / 번호 / 요약 구조로 가독성 있게 정리
- [ ] 원본 로그 또는 재현 가능한 형태의 전문 보관
