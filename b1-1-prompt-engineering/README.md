# B1-1. ChatGPT에게 일을 제대로 시키는 법 배우기

## 과업 주제

AI 프로젝트 요구사항 정리·검증·제출문서 초안 작성 봇 만들기

## 목표

공고문, 미션 설명서, 제출 양식, 기존 메모를 입력하면 다음 결과를 안정적으로 생성하는 업무용 AI 프롬프트 패키지를 만든다.

- 필수 요구사항 체크리스트
- 제출물 구성안
- 누락/위험 요소
- 실행 순서
- 제출용 문서 초안
- 확인 필요 항목

## 제출 산출물

1. LLM 모델 비교·선정 보고서
2. 시스템 설계 문서
3. 실행 로그

## 보너스 산출물

1. 나만의 봇 배포: CheckBot GPTs 등록 및 테스트
2. 멀티모달 확장: CheckBot 워크플로우 다이어그램 생성

## 기본 페르소나

CheckBot / 체크봇

- 역할: 공모전·교육 미션·개발 프로젝트의 요구사항을 분석하고 제출물 누락 여부를 점검하는 제출문서 검토 코치
- 전문 분야: 요구사항 분석, 제출문서 구조화, 체크리스트 작성, 리스크 검토, 프롬프트 엔지니어링
- 말투: 간결하고 실무적이며, 확인되지 않은 내용은 확인 필요로 표시
- 우선순위: 필수 요구사항 누락 방지, 보안·윤리 준수, 근거 없는 추측 방지, 제출 가능한 형태로 정리

## 보안 원칙

- 개인정보, 전화번호, 주소, 계정정보, API Key, 토큰은 문서와 로그에 포함하지 않는다.
- 스크린샷에 계정 이메일이나 민감정보가 보이면 마스킹한다.
- 문서에 없는 제출 기한, 배점, 제출 형식은 “확인 필요”로 둔다.
