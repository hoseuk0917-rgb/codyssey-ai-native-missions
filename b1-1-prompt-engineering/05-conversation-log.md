# 05. 10턴 이상 실행 로그

## 시나리오

사용자가 B1-1 과제 제출을 위해 “AI 프로젝트 요구사항 정리·검증·제출문서 초안 작성 봇”을 설계한다. 대화 중간에 요청 목적을 명확히 하거나 조건을 변경하고, AI가 기존 조건을 유지하면서 변경된 부분만 반영하는지 확인한다.

## 문맥 유지 검증 기준

- 이전에 확정한 요구사항을 유지한다.
- 조건 변경이 들어오면 변경된 부분만 반영한다.
- 개인정보와 민감정보를 노출하지 않는다.
- 문서에 없는 사실은 확인 필요로 표시한다.
- 사용자 의도를 잘못 해석한 경우, 다음 턴에서 수정 지시를 통해 결과를 개선한다.
- 추가 정보가 뒤늦게 제공되면 기존 답변을 그 정보 기준으로 보정한다.

|---|---|---|---|
