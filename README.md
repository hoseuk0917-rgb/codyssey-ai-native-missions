# Codyssey AI Native Missions

코디세이 AI 네이티브 과정 미션 산출물과 작업 로그를 정리하는 저장소입니다.

## 목적

- AI 도구 학습 미션 산출물 관리
- 프롬프트, 모델 비교, 실행 로그, 검증 기록 보관
- 이후 노코드 자동화, 멀티모달 제작, UI/UX, 뉴스 요약 자동화 프로젝트까지 확장

## 폴더 구조

```text
codyssey-ai-native-missions/
  b1-1-prompt-engineering/
  b1-2-ai-advertisement/
  b1-3-nocode-automation/
  project-a-uiux-design/
  project-b-news-summary-automation/
  project-c-social-content/
```

## 진행 순서

1. B1-1: ChatGPT에게 일을 제대로 시키는 법 배우기
2. B1-2: AI로 글·그림·영상 만들어 나만의 광고 만들기
3. B1-3: 코딩 없이 자동화 워크플로우 만들기
4. Project A/B/C 확장

## 보안 원칙

- API Key, 토큰, 비밀번호는 저장소에 올리지 않는다.
- 대화 로그에는 개인정보를 직접 포함하지 않는다.
- 제출용 스크린샷에는 계정 이메일과 토큰을 마스킹한다.
- 사실·수치·정책은 근거 또는 확인 필요 표시를 남긴다.
