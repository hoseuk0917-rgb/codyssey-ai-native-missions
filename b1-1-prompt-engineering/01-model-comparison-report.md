# 01. LLM 모델 비교·선정 보고서

## 1. 비교 목적

동일한 업무 과업을 3종 이상의 LLM에 입력하여, 요구사항 분석·문서화·검증 업무에 가장 적합한 모델을 선정한다.

## 2. 비교 과업

```text
공고문 또는 미션 설명서를 읽고 다음 항목을 정리하라.
1. 필수 제출물
2. 기능 요구사항
3. 제약사항
4. 보안/윤리 주의사항
5. 누락 위험 요소
6. 바로 실행 가능한 작업 순서
```

## 3. 비교 대상 모델

| 모델명 | 사용 환경 | 요금제 | 사용일 | 비고 |
|---|---|---|---|---|
| ChatGPT | 웹/앱 | 유료/무료 | YYYY-MM-DD |  |
| Claude | 웹/앱 | 유료/무료 | YYYY-MM-DD |  |
| Gemini | 웹/앱 | 유료/무료 | YYYY-MM-DD |  |

## 4. 평가 축

| 평가 항목 | 설명 | ChatGPT | Claude | Gemini |
|---|---|---:|---:|---:|
| 요구사항 누락 방지 | 필수조건을 빠뜨리지 않는가 |  |  |  |
| 한국어 문서화 품질 | 제출문서로 읽기 쉬운가 |  |  |  |
| 근거 기반 검토 | 문서에 있는 내용과 추측을 구분하는가 |  |  |  |
| 환각 억제 | 없는 내용을 단정하지 않는가 |  |  |  |

| 비용/접근성 | 실제 과제 수행에 부담이 적은가 |  |  |  |
